# Product screens (landing-page hero reference)

Drop real screenshots of the actual running app here — the home screen,
Moment Coach mid-conversation, a check-in, whatever best represents the
product.

## Why this folder exists

`design/design.md` §18 (section 2, "Hero") documents that the current
landing-page hero deliberately ships **without** a phone/device mockup:

> No fabricated product screenshots — ships without a phone mockup until
> real product screenshots are supplied (see §23 Don't example).

§23's Do/Don't list is explicit that fabricated screenshots are a "Don't"
for this project — CalmGuide's own safety docs are strict about not
overclaiming, and an invented mockup would misrepresent a real,
clinically-adjacent tool. So the hero stays screenshot-free until genuine
captures land here.

Once real screenshots are added to this folder, point me at it and I'll
wire an actual device mockup into the hero (§18) using them — cropped/
framed as needed, not redrawn or altered.

Nothing in this folder is wired into the app automatically — it's just a
drop zone until real screenshots exist and a mockup is built from them.
